#api-setup-practice

## 概要
COACHTECH 教材 Tutorial 11-1 「API開発環境の構築と疎通確認」で作成して成果物。API開発専用のプロジェクトをセットアップ、疎通確認。

## 使用技術
- PHP 8.x
- Laravel 10.x
- REST API (JSONレスポンス)
- Postman(動作確認)

## 学んだこと
- APIの基本概念、開発環境のセットアップ方法。
- JSONの構造、JSON形式でのレスポンスを返す方法。
- Postmanを使用した動作確認。

## 動作確認
PostmanでGETリクエストを送信すると{"message":"hello,API!"}というJSONが返ってくる。
